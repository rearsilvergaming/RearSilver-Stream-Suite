Commands

A quick reference for viewers, moderators and broadcasters. The role badges below follow the permissions configured in Settings.

Song requests

!sr <title> <artist>
Search YouTube and add the best match to the request queue.
!sr <YouTube link>
Request a specific YouTube or YouTube Music video.
!sr <Spotify link>
Connect Spotify in Accounts
Request a specific Spotify track through the connected Spotify account.

Playback

!play
Start or resume the current track.
!pause
Pause the current track.
!skip
Skip to the next request, or to the fallback playlist when requests are empty.
!restart
Restart the current track from the beginning.
!previous / !prev
Return to the previously played track.

Queue moderation

!remove #R<number>
Remove the exact waiting request identified by its stable request ID—for example, !remove #R12.
How request IDs work: every accepted request receives a stable ID such as #R12 in chat. The ID stays with that request even if the queue order changes, making moderation safe and unambiguous.
